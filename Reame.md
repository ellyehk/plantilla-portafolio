# 🚀 Plantilla de Portafolio Web Editable (PRUEBAWEB) ✨

> Muestra tus proyectos al mundo en minutos. Una plantilla **modular, responsiva** y muy fácil de personalizar.

## 💡 Acerca del Proyecto
Esta es una plantilla de portafolio web robusta y moderna. Utiliza **Bootstrap 5** y **JavaScript (Vanilla)** para implementar una **carga dinámica de contenido** y efectos interactivos (como modales), garantizando una experiencia de usuario fluida.

---

## 🌟 Características Clave
| Característica | Descripción |
| :--- | :--- |
| **🎨 Diseño Responsivo** | Se adapta perfectamente a cualquier dispositivo gracias a **Bootstrap 5**. |
| **🔗 Carga Dinámica** | Los detalles de los proyectos se cargan en **modales** desde archivos HTML, facilitando la edición. |
| **🚀 Interactividad** | Incluye efectos visuales avanzados con la librería **Swiper.js**. |
| **✍️ Fácil Personalización** | Estructura de archivos muy clara y fácil de editar (HTML y CSS). |
| **✅ Secciones Esenciales** | Incluye: **Acerca de Mí**, **Proyectos** y **Contacto**. |

---

## 🛠️ Tecnologías Utilizadas
* **HTML5** & **CSS3 (Bootstrap 5)**
* **JavaScript (Vanilla)**
* **Swiper.js** (Para carruseles y efectos de *swipe*)
* **Figma** (Utilizado para el prototipado y diseño inicial)
* **PHP** (Se usa `index.php`, si bien el *core* es HTML/CSS/JS)
